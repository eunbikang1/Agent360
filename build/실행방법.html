🚀 Agent360 Dashboard 실행 방법

✅ 이 폴더를 회사 내부망에서 사용할 수 있습니다
아래 방법 중 하나를 선택하여 실행하세요.

방법 1: 원클릭 실행 (Windows) - 권장 ⭐

1단계: 실행.bat 파일을 더블클릭
2단계: 브라우저에서 자동으로 열림 (또는 수동으로 아래 주소 입력)
http://localhost:3000
3단계: 종료하려면 터미널 창에서 Ctrl+C 누르기
💡 필요사항: Node.js가 설치되어 있어야 합니다
없다면 → https://nodejs.org 에서 다운로드 (LTS 버전 권장)

방법 2: 원클릭 실행 (Mac/Linux)

1단계: 터미널을 열고 이 폴더로 이동
2단계: 아래 명령어 실행
./실행.sh
3단계: 브라우저에서 접속
http://localhost:3000

방법 3: Python 사용 (간단)

1단계: 터미널/명령 프롬프트를 열고 이 폴더로 이동
(Windows: 폴더 주소창에 cmd 입력 후 엔터)
2단계: Python 명령어 실행
# Python 3 사용 시 python -m http.server 8000 # Python 2 사용 시 python -m SimpleHTTPServer 8000
3단계: 브라우저에서 접속
http://localhost:8000

방법 4: 회사 내부 웹 서버에 배포 (IT 부서 협조 필요)

1단계: 이 폴더의 모든 파일을 회사 내부 웹 서버에 업로드
2단계: 회사 인트라넷 주소로 접속
예: http://내부서버IP/agent360
3단계: 모든 직원이 브라우저로 바로 접속 가능
✅ 장점: 한 번만 배포하면 누구나 URL로 접속 가능 (가장 편리)

❓ 문제 해결

Q: "npx 명령어를 찾을 수 없습니다" 오류

A: Node.js를 설치하세요 → https://nodejs.org

Q: 포트가 이미 사용 중이라는 오류

A: 다른 포트 번호를 사용하세요

npx serve -s . -p 3001

Q: 파일이 제대로 로드되지 않음

A: 브라우저 캐시를 삭제하고 새로고침 (Ctrl+F5 또는 Cmd+Shift+R)

Q: 한글이 깨져 보임

A: 이 HTML 파일을 브라우저로 열면 정상적으로 보입니다

  • 이 파일들은 정적 파일이므로 인터넷 연결 없이도 작동합니다
  • 회사 내부망에서만 사용 가능합니다
  • 현재 데이터는 샘플 데이터입니다 (실제 데이터 연동 필요 시 별도 작업)
