================================================================================
Agent360 Dashboard 실행 방법
================================================================================

이 폴더를 회사 내부망에서 사용하시려면 아래 방법 중 하나를 선택하세요.

################################################################################
방법 1: Node.js가 설치되어 있는 경우 (권장)
################################################################################

1. 터미널/명령 프롬프트를 열고 이 폴더로 이동합니다
   (Windows: 폴더 주소창에 'cmd' 입력 후 엔터)

2. 아래 명령어를 입력하고 엔터:

   npx serve -s .

3. 브라우저에서 아래 주소로 접속:

   http://localhost:3000

4. 종료하려면 터미널에서 Ctrl+C를 누르세요

※ Node.js가 없다면:
  - https://nodejs.org 에서 다운로드 및 설치 (LTS 버전 권장)

################################################################################
방법 2: Python이 설치되어 있는 경우
################################################################################

1. 터미널/명령 프롬프트를 열고 이 폴더로 이동합니다

2. Python 버전에 따라 명령어 입력:

   Python 3:
   python -m http.server 8000

   Python 2:
   python -m SimpleHTTPServer 8000

3. 브라우저에서 아래 주소로 접속:

   http://localhost:8000

4. 종료하려면 터미널에서 Ctrl+C를 누르세요

################################################################################
방법 3: 회사 내부 웹 서버에 배포 (IT 부서 협조 필요)
################################################################################

1. 이 폴더의 모든 파일을 회사 웹 서버에 업로드

2. 회사 인트라넷 주소로 접속
   예: http://내부서버IP/agent360

3. 모든 직원이 브라우저로 바로 접속 가능

################################################################################
주의사항
################################################################################

- 이 파일들은 정적 파일이므로 인터넷 연결 없이도 작동합니다
- 회사 내부망에서만 사용 가능합니다
- 데이터는 샘플 데이터입니다 (실제 데이터 연동 필요 시 별도 작업)

################################################################################
문제 해결
################################################################################

Q: "npx 명령어를 찾을 수 없습니다" 오류
A: Node.js를 설치하세요 (https://nodejs.org)

Q: 포트가 이미 사용 중이라는 오류
A: 다른 포트 번호를 사용하세요
   예: npx serve -s . -p 3001

Q: 파일이 제대로 로드되지 않음
A: 브라우저 캐시를 삭제하고 새로고침 (Ctrl+F5)
