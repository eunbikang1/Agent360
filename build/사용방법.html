✨ Agent360 Dashboard 사용 가이드

🎉 이제 index.html 파일을 더블클릭하면 바로 실행됩니다!

📂 사용 방법 (매우 간단)

  1. index.html 파일을 찾습니다
  2. 더블클릭하여 엽니다
  3. 끝! 브라우저에서 대시보드가 열립니다

🔗 페이지 이동

대시보드 내에서 메인 화면 ↔ 지점 상세 화면 이동이 가능합니다.

URL에 # 기호가 포함됩니다 (정상입니다)

  • 인터넷 연결이 필요 없습니다 (오프라인 작동)
  • 현재 데이터는 샘플 데이터입니다
  • 실제 데이터 연동은 별도 작업이 필요합니다
