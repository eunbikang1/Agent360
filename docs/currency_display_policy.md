# 금액 표시 단위 정책

## 1. 기본 원칙

### 1.1 화면별 기준 단위
- **메인 화면 (Agent360Dashboard)**: 백만원 단위
  - 이유: 지점장 개인 실적 및 여러 지점 비교를 위한 큰 금액 단위
- **지점 상세 화면 (Branch360Dashboard)**: 천원 단위
  - 이유: 개별 지점의 작은 금액(6만원~수천만원)까지 명확히 표현

### 1.2 APE/MMP 기준 전환
- **APE (Annual Premium Equivalent)**: 연간 환산 보험료
  - 정수 표시 (소수점 없음)
- **MMP (Monthly Maintenance Premium)**: 월 유지보험료
  - MMP = APE / 12
  - 소수점 1자리 표시

### 1.3 툴팁 표시
- **모든 툴팁**: 원 단위로 정확한 금액 표시
- **기준**: 항상 APE 기준 원 단위 (MMP 선택 시에도 동일)
- **이유**: 반올림으로 인한 정보 손실 방지

## 5. 구현 규칙

### 5.1 데이터 저장
- **모든 데이터는 APE 기준으로 저장**
- 단위: 만원 또는 원 (일관성 유지)
- MMP 변환은 표시 단계에서만 처리

### 5.2 화면 표시 함수

#### Agent360Dashboard (백만원 단위)
```typescript
const formatCurrency = (amount: number, kpi: 'APE' | 'MMP' = 'APE') => {
  const millions = amount / 1000000;
  if (kpi === 'MMP') {
    return `${millions.toFixed(1)}백만원`; // 소수점 1자리
  } else {
    return `${Math.round(millions)}백만원`; // 정수
  }
};
```

#### Branch360Dashboard (천원 단위)
```typescript
const formatCurrency = (amount: number) => {
  const adjustedAmount = performanceType === 'MMP' ? amount / 12 : amount;
  const thousands = Math.round(adjustedAmount / 1000);
  return `${thousands.toLocaleString()}천원`;
};
```

### 5.3 툴팁 표시 함수

#### 공통 (원 단위, APE 기준)
```typescript
// Agent360Dashboard
{myKPI.goalAchievement.target.toLocaleString()}원
{myKPI.goalAchievement.actual.toLocaleString()}원

// Branch360Dashboard
{(corePerformance.targetApe * 10000).toLocaleString()}원
{(corePerformance.currentApe * 10000).toLocaleString()}원
```

### 5.4 MMP 변환 규칙
1. **화면 표시**: `amount / 12` 후 해당 단위로 표시
2. **툴팁**: 항상 APE 기준 원 단위 (변환 없음)
3. **소수점**: APE는 정수, MMP는 소수점 1자리 (백만원) 또는 정수 (천원)

## 6. 예외 케이스

### 6.1 0원 또는 매우 작은 금액
- 백만원 단위: 0백만원 (0.0백만원)
- 천원 단위: 0천원
- 툴팁: 정확한 원 단위 표시

### 6.2 극단적 달성률
- 1001%, 741% 등 1000% 초과 가능
- 목표가 매우 작은 경우 (6만원 Plan, 600만원 Actual)

### 6.3 음수 금액
- 없음 (모든 실적/목표는 양수)

## 7. 일관성 체크리스트

### 화면 표시
- [ ] 메인 화면: 백만원 단위 (APE 정수, MMP 소수점 1자리)
- [ ] 지점 상세: 천원 단위 (APE/MMP 모두 정수)
- [ ] 단위 표시: [단위: 백만원] / [단위: 천원] 명시

### 툴팁 표시
- [ ] 모든 툴팁: 원 단위
- [ ] APE 기준으로 표시 (MMP 선택 시에도 동일)
- [ ] 정수로 표시 (toLocaleString() 사용)

### APE/MMP 전환
- [ ] 데이터는 APE 기준으로 저장
- [ ] MMP = APE / 12
- [ ] 화면 표시 함수에서만 변환 처리

### 가독성
- [ ] 1,000 단위 구분 쉼표 (toLocaleString)
- [ ] 불필요한 소수점 제거 (APE)
- [ ] 필요한 소수점 1자리 유지 (MMP 백만원)
